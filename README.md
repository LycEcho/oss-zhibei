# 开源指北

> 先懂类型，再选项目 —— AI 起草、人工核验的开源项目选型导航。
> 每个开源类型一篇「选型意见」：**默认选谁、什么情况换、不适合谁**。

**在线访问**：https://lycecho.github.io/oss-zhibei/ （开启 Pages 后生效）

不按编程语言分，按「一次选型决策里会放在一起比的那一组」分——AI 时代，语言不是边界，用途才是。

---

## 这是什么

找开源项目不难，难的是「敢不敢用」：还活着吗？协议能商用吗？跟另外五个差不多的比该选谁？
本项目不罗列项目——每个类型先讲清楚「这是什么、怎么选」，默认推荐一句话给答案，全部判断挂证据和日期。

三条内容铁律：

1. **判断永远由人背书** —— AI 只起草和供证据，每页盖「核验戳」：谁核验的、什么时候、依据什么
2. **不写正确的废话** —— 「各有优劣看场景」出现即返工；写不出「默认选谁」就照实说（见新星观察区）
3. **负面空间也是内容** —— 停更警示区、闭源对照项、边界物种裁决，都在页面上

## 贡献一个类型

内容与界面完全分离：**数据在 `data/types/` 下，一个类型一个文件**，界面引擎自动加载渲染。

1. 在 `data/types/` 新建一个 `.js` 文件（照抄现有文件结构）
2. 把路径登记进 `data/types.js` 的清单数组（顺序 = 首页卡片顺序）
3. 提交 PR —— 页面自动出现新类型，搜索自动索引

### 数据字段说明

```js
window.TYPE_DATA.push({
  id: "my-type",              // 必填 · 唯一英文标识（页面路由用）
  name: "类型名",              // 必填 · 中文显示名
  kw: "关键词1 关键词2",        // 必填 · 搜索关键词（空格分隔）
  one: "一句话说明",           // 必填 · 首页卡片与页首简介
  date: "2026-10-20",         // 必填 · 核验日期（数据是哪天抓的）
  src: "发现来源",             // 必填 · 如「四层漏斗 · 双圈交叉」
  status: "ok",               // 必填 · "ok"=有默认推荐 / "obs"=观察中
  count: 11,                  // 必填 · 已采集项目数
  fit: ["适合谁", ...],        // 推荐 · 适合的场景
  nofit: ["不适合谁", ...],    // 推荐 · 不适合的场景（禁写套话）
  dims: [["维度","说明"],...], // 推荐 · 该类型特有的选型维度
  segs: [...],                // 必填 · 形态分段（见下）
  dead: [...],                // 可选 · 停更警示 / 边界物种
  myths: [["误区","真相"],...],// 可选 · 常见误区
  edge: "...",                // 可选 · 与相邻类型的边界
  legal: "...",               // 可选 · 合规位（灰色地带类型必备）
  isObs: true,                // 观察区专用
  obsNote: "...",
  obsList: [["项目","一句话","细分","证据"],...]
});
```

`segs`（形态段）—— **每个形态段必须能写出「默认选谁」，写不出就拆段或放观察区**：

```js
segs: [{
  name: "形态名", tag: "副标签",
  def: { proj: "默认推荐项目", meta: "★ 星数 · 协议 · 活跃度", why: "为什么是它（要能指导具体的人做具体选择）" },
  risk: "⚠ 风险提示（可省略）",
  swaps: [{ t: "什么情况下换", p: "换成谁", m: "★ 数据", d: "为什么" }],
  nofit: "该形态不适合谁（可省略）"
}]
```

## 内容从哪来（发现漏斗）

```
① 热度雷达（GitHub Trending / HN / V2EX / 掘金，全部带时间戳证据）
② 双圈交叉确认（中英文两个圈子都讨论的才算真热；转载只算一个源）
③ 验证闸门（push 日期 > star；协议以 LICENSE 文件为准）
④ 类型裁决（写得出「默认选谁」的建类型页；太新的进观察区）
```

沉默但可靠的项目走「采用验证」通道：发行版自带、软件源常青、被写进默认安装步骤。
